### 👨‍💻 Perfil de Ingeniería

Desarrollador de software especializado en la construcción de **sistemas backend empresariales, arquitecturas desacopladas y de alta concurrencia**. Mi especialidad reside en **Java 21 LTS y el ecosistema Spring Boot**, aplicando rigurosamente **Domain-Driven Design (DDD)**, **Arquitectura Hexagonal (Puertos y Adaptadores)** y control versionado de bases de datos mediante **Flyway en PostgreSQL 16**.

Integro **Inteligencia Artificial como co-piloto activo de ingeniería**, diseñando prompts estructurados y flujos agénticos para acelerar el prototipado, garantizar exhaustividad en testing unitario (JUnit 5 / Mockito) y reducir fricción técnica sin sacrificar la solidez arquitectónica.
